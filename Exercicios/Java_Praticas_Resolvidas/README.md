# Práticas de Java - Resolvidas

Material organizado a partir das quatro práticas enviadas:
1. Prática 1 - Criando classes e objetos básicos
2. Prática 1 (parte 2) - Tratamento de Strings e Datas
3. Prática 2 - Arrays e Collections
4. Prática 2 (parte 2) - HashMaps

## Como usar no IntelliJ
Cada pasta de prática pode ser aberta como um projeto separado.
Não coloque todas as pastas no mesmo projeto, pois algumas possuem classes Main e/ou Produto repetidas.

## Observação importante sobre a Prática 1 - Hogwarts
O enunciado lista os atributos coragem, inteligência, ambição e lealdade, mas as fórmulas também usam
"estrategia" e "criatividade". Para que o exercício seja executável, essas duas propriedades foram incluídas
como atributos adicionais.

## Observação sobre a Prática 2 - Arrays
O enunciado pede que ações como incluir, excluir e alterar itens sejam feitas por métodos das classes,
e não diretamente no main. O código segue essa orientação.

## Observação sobre a Prática 2 - HashMaps
A integração com compra foi incluída: a compra verifica existência, verifica estoque suficiente,
retira a quantidade do estoque e adiciona o item à fatura.
